# Animated Java fixture provenance

The `resources/` and `datapacks/` trees in this directory are unmodified output
from Animated Java 1.10.2. They were exported from upstream's
`test-packs/1.20.4/blueprints/armor_stand_minimal_1.20.4.ajblueprint` at commit
`a5fc548d2a53cc0887fa070db33ccfcef1cd3541` using Blockbench 5.1.4. Exact
artifact, blueprint, template, and output hashes are recorded in `fixture.json`.

Animated Java is copyright (C) 2023 Titus Evans and is distributed under the
GNU Affero General Public License, version 3 or any later version. The upstream
project is <https://github.com/Animated-Java/animated-java>; its license is
reproduced in `LICENSE-Animated-Java.txt`.

This notice and the license file sit outside the two exported roots, so they do
not alter the fixture's pinned output manifest.
